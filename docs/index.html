MATHEMATICAL ENGINE

Continuous Posture Physics

We calculate body angles using trigonometric coordinate vectors. Scoring operates dynamically on a continuous scale to prevent artificial data discontinuities in longitudinal charts.

Geometrical Formulas

Weighted Torso Angle: θ_torso = (θ_lower_spine * 0.3) + (θ_upper_spine * 0.7)
Upper back segment (Spine ➔ Shoulder): θ_upper_spine = atan2(abs(x_shoulder - x_spine), abs(y_spine - y_shoulder))
Lower back segment (Hip ➔ Spine): θ_lower_spine = atan2(abs(x_spine - x_hip), abs(y_hip - y_spine))
Neck Inclination Angle (Shoulder ➔ Head): θ_neck = atan2(abs(x_head - x_shoulder), abs(y_shoulder - y_head))
